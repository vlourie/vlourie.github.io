XP Mirror

XP Mirror is a small command-line tool used by the maintainer of the X-Piratez HD mod (a community modification of the open-source game OpenXcom Extended) to keep a copy of its public release files on the maintainer's own Google Drive, so that the mod launcher can download updates from there when the main server is slow or unreachable.

The tool is used only by its author with their own Google account. It stores no data about any other person. See the privacy policy.

Contact: vlourie@gmail.com
